# 来源与许可

## 人物资产

人物基体、目标变形、骨骼、站姿、皮肤、头发、服装、眼睛及其他身体部件来自 MakeHuman / MPFB 官方开放资产。

- MPFB 2.0.17：源代码为 GPLv3；本项目使用其生成模型，不分发修改后的 MPFB 程序逻辑。
- MPFB bundled assets：CC0 1.0 Universal。
- MakeHuman System Assets：CC0 1.0 Universal。
- MakeHuman System Poses：CC0 1.0 Universal。
- MakeHuman 团队声明 MPFB 的模型、渲染和导出结果由使用者处置，相关资产按 CC0 提供。

官方来源：

- https://github.com/makehumancommunity/mpfb2
- https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html

本项目对人物的体型参数、脸部比例、皮肤与服装组合、站姿、命名、展示灯光和导出结构进行了重新组合与制作。

## 机器人参考几何

机器人关节树与参考网格来自 Unitree Robotics 官方 `unitree_ros` 仓库中的 G1 29-DOF with hand 描述，许可证为 BSD 3-Clause。本项目移除了 logo 网格，并重新制作了黑色材质、命名与自然站姿。该资产仅作为仿真开发参考，不表示 Unitree Robotics 对 MindSpace 的认可或背书。

官方来源：https://github.com/unitreerobotics/unitree_ros
