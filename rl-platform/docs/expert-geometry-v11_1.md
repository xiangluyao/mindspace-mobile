# Human Layer v11.1：专家视角遮挡与穿模修复

截图中的桌椅缺面可由原餐厅GLB的材质导出重现：实心木材、墙面和地板被标记为BLEND，Three.js载入后关闭深度写入。以人物眼高查看时，大面积地板绘制会盖住桌椅。实际解码原始底色贴图并检查完整像素后，对50个已确认不透明的材质恢复正常深度遮挡；玻璃、植物镂空、盘子花纹和原本隐藏的桌布不套用此规则。原餐厅GLB不变。

第一人称不再继承总览2.7m高的剖切，光学画面与拾取射线均使用完整房间。切到跟随或全景、退出角色后，恢复原总览剖切偏好。水平与垂直视野大小保持各角色配置。

携物移动以前只有0.30m人体圆形碰撞范围，而P14托盘会伸至身体前约0.51m。现在专家控制的Carry/Serve采用各服务员原动作的托盘包络，检测平移和转动的连续扫掠，碰到墙体/家具时截到安全姿态；后退或反向转动可退出接触。普通未携物行走仍使用原规则。已用原餐厅墙体和原GLB逐帧验证，不以相机裁切替代碰撞。

P14马甲原后片只有38顶点、18面，固定平面部分位于衬衫内部。Blender修订从实际衬衫表面建立后片及肩部，保留原衬衫与前片，并转移同源蒙皮权重。修订作为独立GLB与Blender工程保存，通过角色目录的modelFile加载；原始16个人物文件保留。

这是针对已复现问题的渲染、服装与携物几何修复；未把平面运动系统替换成完整刚体/布料物理。手工改骨骼/服装形状或导入新角色时，携物包络仍需对应校准。历史记录的原始数据和已保存图像不改写，重新渲染回放会使用修正后的场景遮挡和服装。
