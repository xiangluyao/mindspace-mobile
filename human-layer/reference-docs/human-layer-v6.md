# Human Layer v6 使用说明

五个页面始终共用同一餐厅与人物状态。主平台顶部 **Human Layer ▾** 和人物页内部下拉菜单均可切换；直接链接可使用 `human-layer.html?section=personas`，支持 `overview / personas / actions / events / expert`。

## 总览窗口

保留餐厅场景、16 位人物、六层社会感知面板、现有餐椅和避障路径。人格名称显示在人物检查面板，可点击进入人格库。顾客仍按规则驱动的消费流程活动。

## 人格库

预置 10 份可复制、编辑的合成餐饮人设，分别保存消费关注、表达方式与可选的大五仿真参数。每位顾客独立分配档案；初始不按人物外貌推断人格。右侧选择后自动保存到当前浏览器，可通过 JSON 搬到另一台电脑。

「店铺与点评」保存 yf_dianping 公开 notebook 中有限的店铺和评分样例及其来源。完整语料尚未导入，样例没有提供的店名不补造。可在「LIWC 与导入」导入筛选后的点评 CSV 和外部 LIWC 结果；须填写实际词典名、版本、语言和单位。正式 LIWC 词典与分析器不包含在软件中。

点评、LIWC 输出和合成人格参数分别存放。导入不会自动把评分或词频转换成真实人格、情绪、耐心时长或同行关系。详细字段与容量限制见 [人格库说明](persona-library.md)。

当前绑定档案进入后续行为算法的上下文；默认规则没有利用人格参数改变行为。因此，“绑定人格”和“人格已通过训练影响行为”是两个不同的状态。团队框选和关系配置接口后续再接入。

## 动作库

按顾客、厨师、服务员筛选，并选择具体人物。独立三维预览加载该人物 GLB 中的真实骨骼动画，支持播放、暂停、拖动进度、速度、循环、显示骨骼和旋转视角。

点击「应用到场景」后返回总览展示结果，同时关闭自主调度，避免岗位调度马上覆盖手动动作。需要恢复日常活动时，点击场景顶部「顾客自主 · 关」。坐姿、用餐等动作仍需预留并到达餐厅现有的可用椅子；独立预览中的姿态不代表场景中已成功落座。

本轮复用现有 Blender 人物、53 根骨骼和已制作的岗位动作，没有重新生成外观模型。动作预览不附加新的餐凳到餐厅。

## 事件库

支持请求点单、请求上菜、请求结账、寻找现有空座和从座位起身。可以选择顾客、服务距离并保存已支持类型的自定义演练模板。类型、在场状态、消费阶段、座位和当前服务任务均经过验证。

- 请求点单：已坐稳且在浏览菜单或请求点单阶段。
- 请求上菜：等待餐品或请求上菜阶段。餐品未就绪时记录“催菜”，仍等待原准备时间。
- 请求结账：用餐、交谈或请求结账阶段。
- 找座：没有已占用或预留座位，且有可达空椅。
- 离座：已坐稳，未处于服务任务或结账中，按原餐椅位置起身；稍后再寻找可用座位。

受理只表示事件进入调度，不表示服务员已经到达或服务已经完成。事件记录页可筛选、检查实际结果与导出当前页面保留的日志；刷新后运行期日志重新开始，自定义模板保存在浏览器。未实现的团队与其他事件明确显示为预留，不能执行。

## 进入角色 / 专家

选择此页面会打开示范控制面板。点击「新建一次示范」或顶部进入角色按钮，填写示范者编号、绑定服务员并选择可写的文件保存目录；点击开始才新建一次 episode。

v7 将视野大小与观察方向分开：第一人称默认水平 90°、垂直 60°，两项独立设定并按人物保存，窗口变化时使用深色遮罩保持角宽。偏转与俯仰收在「观察方向」中；偏转相对身体，水平正值朝左、俯仰正值抬头，改变观察方向不会改变身体朝向。跟随与全景保留普通全视窗透视。详见 [人物视野与眼动坐标](camera-view.md)。

视窗右上角平面图来自同一份真实餐厅地板、家具碰撞框和世界坐标，突出绑定服务员的位置、身体方向、视线及本次路径，其他人物显示为参考点。地图可折叠。选择检查另一个人物不会把轨迹或控制权转给那个人。

进入资料库时场景和采集的仿真时间暂停，键盘不能在后台驱动角色。若已连接真实设备，原始 EEG、眼动与解码输出仍连续保存，附加 `simulationPaused` 和 `workspaceSection` 标记；资料库期间不生成眼动目标或待执行的解码指令。返回场景后恢复进入资料库前的运行状态；顶部始终可返回示范或结束保存。采集及回放期间允许浏览、预览与导出，锁定人格修改、模板修改和场景应用。

回放从保存的帧恢复实际位置与相机参数。默认“跟随录制视角”，手动观察会退出视角同步，可再次勾选恢复；时间轴向前拖动不会显示未来轨迹。旧记录缺失相机参数时明确提示，并保留自由观察。

采集 metadata 保存本次已分配的人格快照、库版本和动作/事件配置；帧保留观察角、视野和世界相机参数，调整产生 `camera_adjusted` 事件。未接真实 EEG 或眼动设备时，信号数据仍为空。详见 [设备与采集接口](capture-api.md)。

## 接口

```js
window.mindspaceHumanLayer.navigate('personas');
window.mindspaceHumanLayer.getPersona('p01'); // 复制的档案；未分配为 null
window.mindspaceHumanLayer.getState();       // workspace、场景、采集状态
window.mindspaceHumanLayer.setBehaviorAdapter((context, proposedAction) => {
  // context.persona 提供分配档案；仍受角色、座椅与导航约束。
  return null; // 保留现有规则的候选动作
});
```

物体类型和几何仍由物体页面负责；本页基于场景注册座位、占用状态和导航约束检查当前可用性。暂未连接外部物体属性服务、语言模型或训练好的人格决策器。
