Human Layer v9 使用说明

人物资料与个人事件编排。总览中查看人物，在L3安排其事件；人格库配置基本资料与可选大五，动作库预览岗位动作，事件库设置物体、距离和路径规则。

v9包含16位人物、192条骨骼动画，以及总览内的个人事件时间序列。模型、场景、采集与回放验收结果见项目根目录的 VALIDATION.md。
场景选择与接入 ↗共用模型的独立配置、场景存储、资产目录和采集隔离。 显示模式与姿态编辑 ↗骨骼、关键节点、肌肉示意、三维拖动、撤销和保存。 人格档案与数据迁移 ↗先选择人物，基础属性、大五人格、行为标签同级独立保存。 动作库与事件定义 ↗按岗位预览骨骼动作；事件类别复选、距离阈值与路径规则。 示范采集与设备接口 ↗真实目录增量保存、JPEG样本、回放，以及EEG/眼动设备桥协议。 专家视野与观察方式 ↗独立水平/垂直角宽、视野外遮罩、相机设置与回放。 顾客同行团队 ↗框选组队、手动定义同行关系与场合；每个人保持独立。 全部入口与功能范围 ↗五个工作页面、当前说明、历史版本与能力边界。

人格页已移除点评与语言分析。基础资料和大五是可配置参数，未填写保持未知；身高不会自行改变模型。仿真使用规则、导航和骨骼动画，设备信号只在真实接入后记录。
