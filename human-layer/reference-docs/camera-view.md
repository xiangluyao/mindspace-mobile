# 人物视野与眼动坐标（v9）

第一人称默认使用水平 **90°**、垂直 **60°** 的普通透视视野。水平范围可设为 30–150°，垂直范围可设为 20–120°；两项独立保存，均为仿真参数，不代表实测的人类视觉边界。水平与垂直范围均通过滑块调整；旁边的数字只读，不再提供水平预设按钮。

## 角色与即时生效

未进入角色时，「配置角色」选择要保存视野的人物，默认与默认采集服务员 p14 一致。它也可以配置顾客或厨师，不会直接接管人物或创建采集。当前配置对象是服务员时，新建采集自动预选该人；对话框显示所选服务员实际保存的水平与垂直视野。切换「扮演角色」会同步右侧配置对象，但不会把另一人的视野参数复制过来。

采集中，「配置角色」锁定为本次绑定角色。修改水平或垂直范围立即更新第一人称相机，同时保存该人的设置；检查另一位人物不会改变控制角色、视野配置目标或地图轨迹。跟随与全景仍采用普通全视窗透视，人物的固定双向范围在第一人称生效。

观察方向放在折叠项中：Yaw 表示相对身体的左右偏转，Pitch 表示抬头或低头。调整方向不改变视野大小，也不改变身体朝向或发送人物动作。

## 窗口变化与视野外遮罩

有效成像矩形的长宽比固定为：

```text
imageAspect = tan(horizontalFov / 2) / tan(verticalFov / 2)
```

页面把这个矩形等比放入整个三维视口并居中。窗口过宽时，两侧出现深色遮罩；窗口过高时，上下出现遮罩。窗口缩放、专家页面铺满或退出铺满只改变成像矩形的像素尺寸，不改变设定的水平和垂直角宽，也不拉伸场景。遮罩是视野外区域。

`observation.camera.imageViewport` 提供成像矩形相对整个三维视口的位置：

```js
{
  x, y, width, height,       // CSS 像素；左上原点
  fullWidth, fullHeight,    // 完整三维视口的 CSS 尺寸
  normalized: {x, y, width, height} // 各项相对完整视口归一化
}
```

## 眼动坐标约定

设备协议的 `gaze.x/y` 和 `scene.pickNormalized(x, y)` 均使用 **完整三维视口（含深色遮罩）** 的 0–1 坐标。左上为 `(0,0)`，右下为 `(1,1)`；不是整个浏览器屏幕、右侧控制面板、地图自身或已经去掉遮罩的光学图像坐标。窗口或 iframe 布局变化后，设备桥应重新使用实际三维画布的屏幕边界转换坐标。

若设备桥输出的是有效成像矩形内部的 `(u,v)`，先转换后再提交：

```js
const r = observation.camera.imageViewport.normalized;
const gazeX = r.x + u * r.width;
const gazeY = r.y + v * r.height;
```

页面内部使用反向映射 `(gazeX-r.x)/r.width`、`(gazeY-r.y)/r.height` 构造真实相机射线。遮罩区域的拾取返回 `null`，不会把视野外位置映射到人物或地面；墙后的人物也不会因加宽视野而成为可见候选。原始合法眼动包仍可被记录和显示光标，`null` 只表示本次没有可拾取的场景候选。候选不会自动执行动作。

角色标签和关键点标签也使用同一个成像矩形投影。地图中的视线扇形从实际成像矩形左右边缘的相机射线投到平面上，身体箭头单独读取人物朝向。

## 记录与回放

采集开始时，`metadata.visionSettings` 保存各人物的配置快照；每帧 `observation.camera` 保存实际 `horizontalFovDeg`、`verticalFovDeg`、`projection: 'perspective'`、`viewportPolicy`、`imageViewport`、位置与四元数。`look.yawDeg/pitchDeg` 独立保存观察方向。采集期间调整产生 `camera_adjusted` 事件；开始时的配置快照不代替之后的逐帧实际相机值。

JPEG 来自完整三维画布，包含当时的深色遮罩，保持该画布比例后缩小；不包含 HTML 控制面板、地图或注视光标。将保存帧中的归一化成像矩形乘以 JPEG 的实际 `width/height`，即可得到该 JPEG 内有效图像的像素边界。

回放默认恢复保存帧的相机姿态及双向视野。若回放窗口尺寸不同，保持录制角宽，重新等比计算当前窗口的成像矩形；保存的 JPEG 不被修改。手动调节会退出「跟随录制视角」，只改变当前回放观察，不写入该人的持久配置；重新勾选即恢复当前录制帧。退出回放后再次进入角色，应用该人物原来保存的设置。

旧记录没有完整相机数据时保留自由观察并显示提示；仅缺少水平角宽时，从旧记录的垂直角宽和相机 aspect 推导。未提供 aspect 的旧记录使用兼容默认值 1，因此不能将其解释为已恢复未知的历史窗口标定。

## 场景集成接口

```js
scene.setActorVision('p14', {horizontalFovDeg: 90, verticalFovDeg: 60});
scene.getActorVision('p14');
scene.getVisionSettings();
scene.setEmbodiment('p14', 'firstperson'); // 自动应用 p14 保存设置
scene.setLookAngles(20, -10);            // 不改变人物身体或视野角宽
scene.getObservation();
scene.pickNormalized(0.5, 0.5);          // 只返回候选，不执行行为
```

`setActorVision` 接受部分更新，无效或越界设置返回 `false`，不会用 180° 或静默近似替代。集成方临时修改回放时必须传 `{persist: false}` 作为第三参数；随包视野控件已自动遵守这一规则。配置按场景与人物保存在当前浏览器的 localStorage；写入失败时本次会话仍有效，面板显示保存错误。
