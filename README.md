# MindSpace 手机浏览版

公开浏览地址：https://xiangluyao.github.io/mindspace-mobile/

## 手机排版

- 默认使用手机实际宽度，不再把整张桌面工作台缩小。
- 算法按节点、连接图、参数、预览和电池库分区；保留原始编辑功能。
- 训练按视窗与设置分区，场景、示范控制与信号分别查看。
- 评测图表纵向排列，实验筛选和辅助工具按需展开。
- 部署卡片纵向排列，数据表格可在局部横向滑动。
- 场景与人因模块保留原三维画面，模型库、属性和功能目录通过底部按钮切换。
- 顶部“桌面全览”可切换完整桌面布局；1024px 以上恢复桌面排版。

此目录仅包含已公开网页的静态发布文件，可独立托管。真实训练后端、硬件采集及电脑目录保存仍需本地完整版。原模型许可证和第三方声明保留在相应目录中。

新增适配仅使用样式与原有 DOM 控件，未修改算法、训练或评测数据。
